# A4趋势交易系统（Android）

基于你提供的规则实现的 Android 程序样例，核心目标是把「资金铁律 + 入场过滤 + 仓位计算 + 止损止盈」落成可执行逻辑。

## 已实现
- 固定交易池：`RB`、`M`、`MA`
- 资金铁律：
  - 最大回撤线（净值 <= 85,000 拒绝开仓）
  - 单笔风险预算 `R=1500`
  - 保证金占用上限 50,000
  - 最大同时持仓品种数 3
  - 单品种最多 2 手
- 信号系统：
  - 趋势过滤：`20日均线斜率 != 0` 且 `ATR/价格 >= 1%`
  - 收盘突破 20 日高/低 触发方向
  - 风险手数：`1500 / (ATR * 合约乘数)`，<1 手不交易
  - 首笔仅开 1 手
  - 双保险止损：`2*ATR` 与 `单手亏损<=2000`
- 异常控制：
  - 跳空 > 2ATR 不入场
  - 连续 3 笔止损暂停新开仓
- 持仓管理规则展示：
  - 10日时间止损
  - 10日突破止盈
  - 浮盈 1.5ATR 加仓 1 手（总计不超过 2 手）

## 注意
此程序为规则执行辅助，不构成投资建议。真实交易请对接实际行情、交易日历、账户数据、风控审计与下单通道。
